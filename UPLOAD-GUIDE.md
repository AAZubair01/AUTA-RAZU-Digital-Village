# RADXtra Upload Guide

Use the existing file paths. Do not rename the PDF links unless you also update the matching HTML button.

## Example upload paths

```text
level2/pdfs/auta-razu/rdx-201-session-1.pdf
level3/pdfs/auta-razu/rdx-301-session-1.pdf
level4/pdfs/auta-razu/rdx-401-session-1.pdf
level5/pdfs/auta-razu/rdx-501-session-1.pdf
```

## Navigation flow

- `level3/index.html` shows the Level 3 confirmation screen.
- `level3/lecturers/index.html` shows the Level 3 lecturer directory.
- `level3/lecturers/auta-razu.html` shows the AUTA-RAZU course workspace.

Repeat the same pattern for Levels 2, 4, and 5.
