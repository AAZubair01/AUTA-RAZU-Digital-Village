# RADXtra PDF Upload Guide

Use the filenames below exactly. The filename itself must not contain `/`.

## Level 2 — RAD-201: Radiation Physics

Upload inside this folder:

```text
level2/pdfs/auta-razu/
```

Use these PDF filenames:

```text
rad-201-session-1.pdf
rad-201-session-2.pdf
rad-201-session-3.pdf
rad-201-session-4.pdf
rad-201-session-5.pdf
```

## Future lecturer filename pattern

For other lecturers, keep the same clean pattern:

```text
course-code-session-number.pdf
```

Examples:

```text
course-01-session-1.pdf
course-01-session-2.pdf
rad-301-session-1.pdf
rad-423-session-3.pdf
```

The folder identifies the lecturer. The filename identifies the course and session.
